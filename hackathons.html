The rules that never change

Same setup, every season.

The theme changes. These don't. Each event's Devpost page has the full rules, including eligibility and team size limits.

hackathon.config
entry_fee     = 0
location      = "online"
open_to       = "students, worldwide"
experience    = "none required"
teams         = "solo or team"
ai_tools      = true        # at every step
build         = "anything that works"
# websites, apps, AI tools, games, hardware

submit = [
  "working prototype",
  "source code",
  "short write-up",
  "2–4 min demo video",
]

Judging

Every hackathon, its own rubric.

Judging criteria change with each theme. The rubric is published when the theme drops, on this page and on the event's Devpost page, so you know how you'll be scored before you start building.
